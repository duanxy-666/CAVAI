CAVAI | CATIA Assessment Validation Artificial Intelligence
一种基于外部api的CATIA模型评测智能体

1.研究背景：Vibecoding工具绘制的较复杂的CATIA模型普遍存在结构耦合错误、根据图片逆向建模时把打光或阴影误识别成筋或肋板、外形满足视觉效果而功能无法实现等问题，人工修改时间成本高，或因特征之间互相嵌套、关联参数改动触发报错等原因难以修改。
2.技术路线：用户上传CATIA模型，Agent调用Python库解析尺寸、拓扑等结构化特征；检测用户使用的API是否支持视觉功能，将适配的数据（描述特征的文本、图片、模型本身等）输入API解析功能和设计意图并对模型分类；API根据模型类别启用对应Skill分析模型尺寸结构是否出现错误、是否支持其预期功能、其在力学方面是否合理；输出Token账本，避免重复上传、多次写入等无效操作和死循环造成浪费。
